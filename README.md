# merkLui/homebrew-tap

Homebrew casks for [DictateLocal](https://github.com/merkLui/DictateLocal), on-device dictation for the Mac.

```bash
brew install --cask merkLui/tap/dictatelocal
```

DictateLocal is signed but not notarized by Apple. The cask therefore removes macOS's download quarantine flag after installing, so the app opens without a Gatekeeper prompt. If you prefer to approve it yourself, download the disk image from the [releases](https://github.com/merkLui/DictateLocal/releases) instead.

The cask is updated automatically by DictateLocal's release workflow.
